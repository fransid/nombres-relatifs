Les nombres positifs et négatifs

Mathématiques – collège (5e – 4e) et révisions

Cours préparé par Sid KHALIFA, professeur de français

Définitions, droite graduée, opérations

1Qu'est-ce qu'un nombre relatif ?

Définition

Un nombre relatif est un nombre muni d'un signe : + pour les nombres positifs (+3 ; +12,5 ; +0,7), − pour les nombres négatifs (−3 ; −12,5 ; −0,7).

Les entiers relatifs (…, −2, −1, 0, +1, +2, …) forment l'ensemble noté ℤ. Avec les décimaux relatifs, on obtient l'ensemble des nombres décimaux relatifs.

Le rôle du zéro

Zéro est à la fois positif et négatif : c'est le seul nombre qui est son propre opposé. Il n'a pas de signe « + » ou « − » en soi.

À quoi servent-ils ?

  • Températures : −5 °C (5 degrés sous zéro)
  • Altitudes : la mer Morte est à −430 m, sous le niveau de la mer
  • Comptes bancaires : un solde de −50 € est un découvert
  • Dates historiques : −52 signifie 52 ans avant notre ère
  • Étages : −1 pour le sous-sol d'un immeuble

Nombres opposés

Deux nombres sont opposés s'ils ont la même distance à zéro mais des signes contraires : +4 et −4.

  • La somme de deux opposés est nulle : (+4) + (−4) = 0
  • Sur une droite graduée, ils sont symétriques par rapport à l'origine O.
Attention

−(−5) = +5 : l'opposé de l'opposé d'un nombre est le nombre lui-même.

3La droite graduée

L'origine O correspond à 0. On choisit une unité et un sens positif (en général vers la droite).

−4−3−2−10+1+2+3+4
Règle d'or

À droite de 0 : nombres positifs. À gauche de 0 : nombres négatifs. −2,5 se place à mi-chemin entre −3 et −2.

4Comparer des nombres relatifs

Règles de comparaison
  • Tout nombre négatif est inférieur à tout nombre positif : −100 < +1
  • Deux positifs : le plus grand a la plus grande distance à zéro : +3 < +8
  • Deux négatifs : le plus grand a la plus petite distance à zéro : −3 > −8 (car 3 < 8)

Astuce : « moins 8 degrés, c'est plus froid que moins 3 degrés », donc −8 < −3. Un nombre est plus grand qu'un autre s'il est situé plus à droite ; ranger dans l'ordre croissant, c'est lire de gauche à droite.

Exemple

Ranger −7 ; +2 ; −3,5 ; 0 ; +0,5 ; −10 :
−10 < −7 < −3,5 < 0 < +0,5 < +2

Encadrement : −3 < −2,4 < −2.

5La valeur absolue

Définition

La valeur absolue d'un nombre est sa distance à zéro, toujours positive ou nulle. On la note |x|.

|+5| = 5 ; |−5| = 5 ; |0| = 0

  • |a| = |−a| : un nombre et son opposé ont la même valeur absolue
  • |a| ≥ 0 toujours
  • Deux nombres ont la même valeur absolue si et seulement s'ils sont égaux ou opposés

6Addition

Règle 1 : même signe

On additionne les distances à zéro et on garde le signe commun.

(+3) + (+8) = +11   (−3) + (−8) = −11   (−4,5) + (−2,5) = −7

Règle 2 : signes contraires

On calcule la différence des distances à zéro et on prend le signe du nombre qui a la plus grande distance à zéro.

(+7) + (−3) = +4   (+3) + (−7) = −4   (+5) + (−5) = 0

Méthode : plusieurs nombres

On regroupe les positifs, puis les négatifs, puis on additionne les deux résultats.

(−4) + (+7) + (−6) + (+3) : positifs +10 ; négatifs −10 ; total 0.

7Soustraction

Règle fondamentale

Soustraire un nombre, c'est ajouter son opposé : a − b = a + (opposé de b).

  • (+10) − (+3) = (+10) + (−3) = +7
  • (+10) − (−3) = (+10) + (+3) = +13
  • (−10) − (+3) = (−10) + (−3) = −13
  • (−10) − (−3) = (−10) + (+3) = −7
Point le plus source d'erreurs

Deux signes « − » qui se suivent deviennent un « + » : a − (−b) = a + b.

Distance entre deux points

AB = |xB − xA|. Avec A(−2) et B(+5) : AB = |5 − (−2)| = |7| = 7.

Moyen mnémotechnique : les amis de mes amis sont mes amis (+ × + = +) ; les ennemis de mes ennemis sont mes amis (− × − = +) ; les amis de mes ennemis sont mes ennemis (+ × − = −).

(+4)×(+3) = +12   (−4)×(−3) = +12   (+4)×(−3) = −12   (−1,5)×(−2) = +3

Plusieurs facteurs

On compte les facteurs négatifs : nombre pair → produit positif ; nombre impair → produit négatif.

(−2)×(−3)×(−1)×(+4) : trois négatifs → négatif ; 2×3×1×4 = 24 ; résultat −24.

9Division

La division suit exactement la même règle des signes que la multiplication.

(+12)÷(+3) = +4   (−12)÷(−3) = +4   (+12)÷(−3) = −4   (−12)÷(+3) = −4   (−7)÷(−2) = +3,5

Attention

On ne divise jamais par 0.

10Priorités opératoires

Ordre à respecter
  • 1. Les parenthèses et crochets, en commençant par les plus intérieurs
  • 2. Les puissances
  • 3. Les multiplications et divisions, de gauche à droite
  • 4. Les additions et soustractions, de gauche à droite
Exemple A

A = (−5) + (−3) × (+4) = (−5) + (−12) = −17

Exemple B

B = [(−2) + (−6)] ÷ (+4) − (−3) = (−8) ÷ 4 − (−3) = −2 + 3 = +1

Écritures allégées : (+3) + (−5) s'écrit 3 − 5 ; 3 − (−5) s'écrit 3 + 5.

11Puissances

Définition

aⁿ = a × a × … × a (n facteurs), et a¹ = a.

  • Exposant pair → résultat toujours positif : (−2)⁴ = +16
  • Exposant impair → signe de la base : (−2)³ = −8

(−3)² = +9   (−3)³ = −27   (−1)⁵ = −1   (−10)³ = −1000

Attention aux notations

−3² = −(3²) = −9, mais (−3)² = +9 : ce n'est pas le même calcul.

12Méthode et erreurs classiques

Check-list avant chaque calcul
  • Repérer les signes (écrire les nombres entre parenthèses aide)
  • Transformer les soustractions en additions d'opposés
  • Appliquer la règle des signes pour × et ÷
  • Respecter les priorités opératoires
  • Vérifier : un produit de deux négatifs est positif, une somme de deux négatifs est négative
